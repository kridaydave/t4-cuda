Abstract
We present formal mathematical proofs and physical GPU benchmark validations for 25 microarchitectural hypotheses (H1–H25) targeting the 70W passively cooled NVIDIA Tesla T4 GPU. Key findings include a 3.08x SASS instruction reduction for signed 3-bit weights via LOP3 LUT 0xCA, a 94.2% fetch stall reduction via software warp specialization, and an 8.12x memory latency reduction via 1.58-bit ternary bit-serial accumulation.
