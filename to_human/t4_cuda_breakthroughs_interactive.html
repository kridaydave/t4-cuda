5. Technical Terminology Glossary

Definitions of key domain concepts across GPU assembly, memory subsystems, and low-bit quantization.

LOP3.B32
Single-cycle 3-input bitwise boolean instruction in NVIDIA CUDA assembly. Evaluates any of 256 boolean truth tables (LUTs) in a single SASS cycle.
WMMA.16.8.8
Warp Matrix Multiply and Accumulate instruction on Turing Tensor Cores, processing 16x8x8 FP16 matrices per warp execution cycle.
Software Warp Specialization
Partitioning CUDA block warps into dedicated Producer (memory read + dequant) and Consumer (Tensor Core compute) warps to eliminate fetch stalls on pre-Ampere GPUs.
Bitplane Decomposition
Decomposing multi-bit integers into binary bitmasks (Sign and Mask planes), enabling 32-element bitwise dot products via LOP3 and POPC accumulators.
In-Register KV Stashing (H24)
Preserving draft model KV-cache vectors inside thread block register files across decode turns, eliminating 100% of DRAM KV reads for context lengths S <= 128.
Constant-Bank Scale Streaming (H25)
Streaming quantization scale parameters directly from GPU __constant__ memory into 8 KB L1 constant caches, eliminating SMEM bank conflicts.
