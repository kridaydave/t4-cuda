2. Mathematical Proofs & Bitwise Boolean Logic

Formally verified bitwise transformations using Turing single-cycle 3-input logic lookup instructions (lop3.b32).

H7: Sub-Byte INT3 Signed Dequantization

LUT 0xCA

Exploits 2's complement symmetry \(s_3 + 4 = \text{sign\_bit\_invert}(s_3)\). Extracted in 13 SASS cycles (vs 40 for naive bfe).

$$\text{LOP3}(S, M, \text{0xCA}) = (S \land M) \lor (\neg S \land \neg M)$$ $$\text{FP16\_Magic\_Exponent} = \text{0x64046404}$$ $$\text{Dequant}(x) = \text{FloatCast}(\text{BitInject}(x \oplus \text{0x4})) - 1028.0$$
  • Instruction Savings: 3.08x instruction reduction (13 vs 40 SASS).
  • Bandwidth Saturation: 303.4 GB/s (94.8% of Turing peak 320 GB/s).
  • Model Compression: 7B model fits in 2.62 GB VRAM.

H23: 1.58-Bit Ternary Bit-Serial LOP3 Accumulation

LUT 0x44 & 0x88

Decomposes ternary weights \(\{-1, 0, 1\}\) into Sign (\(S\)) and Non-Zero Mask (\(M\)) bitplanes.

$$P = (\neg S) \land M \quad (\text{LUT 0x44}), \quad N = S \land M \quad (\text{LUT 0x88})$$ $$\text{DotProduct}(X, W) = \sum_{k} \text{popcount}(P_k \land X_k) - \sum_{k} \text{popcount}(N_k \land X_k)$$
  • SASS Efficiency: 32-element dot product evaluated in 4 SASS instructions.
  • Compression: 10.13x VRAM footprint reduction (7B model = 1.38 GB).
  • Latency Speedup: 8.12x memory access reduction over FP16.

5. Microarchitectural Glossary

Essential domain terminology across Turing GPU hardware, CUDA assembly, and sub-byte quantization math.

LOP3.B32
Single-cycle 3-input bitwise boolean logic instruction in NVIDIA CUDA assembly executing any of 256 truth tables (LUTs) in 1 SASS cycle.
WMMA.16.8.8
Warp Matrix Multiply and Accumulate instruction on Turing Tensor Cores executing $16 \times 8 \times 8$ FP16 matrix operations per warp.
Warp Specialization
Partitioning threads within a CUDA thread block into dedicated Producer (memory fetch) and Consumer (Tensor Core compute) warps to mask memory stalls.
Bitplane Decomposition
Decomposing multi-bit integers into separate binary bitmasks (Sign and Mask planes), enabling fast SIMD popcount bitwise dot products.
Persistent Grid Streaming
Fixing the active CUDA thread block count to match physical SMs (40 blocks on T4), using L2 atomic counter fetching to eliminate wave-tail waste.
Speed-of-Light (SOL)
NVIDIA Nsight Compute metric indicating the percentage of hardware peak memory bandwidth or compute throughput achieved by a CUDA kernel.
